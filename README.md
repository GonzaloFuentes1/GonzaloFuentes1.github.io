# gonzalofuentes1.github.io

Página personal de Gonzalo Fuentes, publicada con GitHub Pages en https://gonzalofuentes1.github.io/.

Sitio estático sin build: `index.html` (español) y `en/index.html` (inglés), con estilos y scripts compartidos en `assets/style.css` y `assets/site.js`, logos en `assets/logos/`, `robots.txt` y `sitemap.xml`. Al cambiar un texto, cámbialo en ambos idiomas. Para ver un cambio localmente:

```bash
python -m http.server 8000
```

Al cambiar el contenido, actualiza `lastmod` en `sitemap.xml`.
